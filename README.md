# Classic Party Trainer - Static GitHub Pages Version

This is the quickest web-hosted version of Classic Party Trainer.

## Upload to GitHub

1. Open https://github.com/Nsteffens16/classic-party-trainer
2. Click **Add file > Upload files**.
3. Upload `index.html` and this `README.md` from this folder.
4. Commit to `main`.
5. Go to **Settings > Pages**.
6. Set **Source** to **Deploy from a branch**.
7. Select **main** and **/root**, then Save.
8. Your site should publish at:
   https://nsteffens16.github.io/classic-party-trainer/

## Notes

- Data saves in your browser using localStorage.
- Use Export/Import JSON to share data between computers or with party members.
- Screenshot OCR uses Tesseract.js from a CDN and should always be manually checked before saving.
